PalimpsestPalimpsest

Government publishes as though the web were permanent. It is not.

Datasets are republished with the past rewritten. Records vanish. Values are corrected without a diff, a version history, or a notice. There is no changelog for the public record — which is why retroactive edits are not merely unnoticed, they are structurally invisible. This is an archive that watches, hashes, and remembers, and can prove its own memory has not been altered.

Finding one

How portals publish decides what can be known about them.

Before any change can be interpreted, one question has to be answered for each dataset: does this publisher edit rows, or rebuild the table? Get it wrong and the conclusion inverts.

The ledger

What actually moved.

Every entry below is a change to a published fact — the hash of a record's semantic fields moved between two observations. Platform identifiers, derived spatial joins and last-written timestamps are excluded from that hash, so a publisher rerunning its pipeline does not appear here.

What the controls remove

Most apparent change is machinery.

Every figure below is produced twice. The first pass classifies changes blind. Its output is then used to measure how each publisher behaves — which columns it recomputes wholesale, whether its keys identify stable entities — and the second pass reclassifies with that knowledge. Only the second is reported.

Finding two

What publishers admit.

The ledger above can only hold changes this archive watched happen, so it fills over days. But where a publisher's timestamps are not saturated, evidence is available immediately — from the portal itself. When a record describing a closed period carries a recent write timestamp, the publisher is asserting that it touched that record.

This is deliberately weaker evidence, and the distinction is load-bearing: the publisher's timestamp shows that a record was rewritten. Only an independent prior observation can show what it previously said. These are therefore reported as assertions, and never counted as observed revisions.

Verification

Evidence, not assertion.

Each observation commits to a Merkle root over every record it saw, and each root is chained to the one before it. Altering any past observation changes every hash that follows, so the archive can demonstrate that its own account of the past is intact — the property the portals themselves lack.

Under observation

The watchlist.

Built from public endpoints only, read at a fixed low rate with an identifying user agent. Palimpsest never authenticates, never writes, and never submits a form. Everything it holds was published to anyone who asked.
